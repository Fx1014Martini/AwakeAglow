## 1. 双主题切换（咖啡 ↔ 鸡尾酒）

**操作路径**：首页 → 顶部 mode-switch 切换「咖啡 / 鸡尾酒」（菜单页同样入口）。

**预期表现**：
- 切换后整页语义色即刻翻转：背景、卡片底、主按钮、标签、图标强调色全部跟随主题 token；鸡尾酒模式不得残留任何咖啡暖棕默认色（P0-2 挂点修复：`view[data-mode].page/.page-root` 命中根节点）。
- 原生导航栏同步变色（`lib/theme.ts` NAVBAR_THEME + 各页 onShow applyPageTheme）：咖啡底色应为 token `#F8F2E9`，鸡尾酒为对应深色/酒色 token，前景文字色随底色可读（P0-3 闭环）。
- 切换模式后：搜索关键词、detailTab 残留被清空；不兼容筛选（如鸡尾酒专属维度）被清空。
- 6 个页面逐一进入均呈现当前主题；mode-switch 自身子节点不被主题选择器误伤。

## 2. 自定义 BrandHeader 导航

**操作路径**：任意页面顶部栏；二级页（详情/对比）重点看返回区。

**预期表现**：
- `navigationStyle: custom` 生效：无原生导航栏，页首为状态栏占位 + 60px BrandHeader。
- 结构：返回按钮位（仅二级页有返回，tab 页保留等宽占位，Logo 不偏移）/ 品牌 Logo（SVG，非 emoji 替代）/ 右侧「更多」按钮。
- 状态栏占位高度正确，刘海/胶囊按钮不遮挡 Logo（不同机型切换验证）。
- 双主题跟随：Logo/图标/底色随 mode 变化，鸡尾酒模式不残留咖啡色。

## 3. 自定义 tabBar：详情/对比页展示与高亮

**操作路径**：
1. tab 页间切换（首页/菜单/收藏/我的），观察 selected 高亮；
2. 菜单页结果卡 → 点入详情页；菜单「对比」模式选两款 → 进入对比页。

**预期表现**：
- `tabBar.custom: true`：custom-tab-bar 组件渲染，SVG 图标（4 项：首页/菜单/收藏/我的），双主题自适配。
- **详情页/对比页（非 tab 页）底部同样挂载 tabBar**（手动挂载），且高亮「菜单」tab（对齐原型 activeTab 语义），不出现无底栏的断层。
- tab 页 onShow 经 `getTabBar()` 同步 selected，来回切换高亮不漂移、不闪烁。
- 底部 safe-area 生效（favorites/profile 页内容不被 tabBar/Home Indicator 压住）。

## 4. 雷达图

**操作路径**：详情页 → 雷达 Tab；对比页（选两款）。

**预期表现**：
- 单产品雷达为 6 维、**0–10 尺度**（server 已对外 ×2 归一），刻度/顶点位置按 max=10 渲染，图形不得只有半满（P0-6 回归点）。
- 每维带中文 label（name_zh），不得显示英文 code。
- 对比页双雷达叠加：第二款 stroke 使用文字色（对齐原型 currentColor），**不得出现金色残留**；图例与左右产品名对应。
- 雷达 Tab 含原型 lead 文案。

## 5. 详情页布局

**操作路径**：菜单/首页任意卡片 → 详情页；依次切「概览 / 配方 / 雷达」Tab。

**预期表现**：
- 模块顺序为 **DetailTabs → Hero**（先 Tab 栏后大图，对齐原型），tabs sticky 42px，选中态为浅底 + 下边框（非仅下划线）。
- 原生导航栏无自绘 topbar 重复（无「双返回/双标题」）；无 id 进入时回退默认产品（不 toast 报错）。
- 概览 Tab：配方比例（前 4 项）与雷达双列 → 制作步骤 → 相似推荐「继续探索同类风格 + 查看更多›」；相似卡**有图、有简介**（server similar 含 image/summary）。
- 配方 Tab：单卡「配方与制作」，原料含中文名 + name_en + `${amount}${unit}` 单位。
- attributes 维度表（咖啡 5 维 / 鸡尾酒含 ABV 等）全部有值，无「—」空行（scene 已映射）。
- 收藏按钮：成功再更新（爱心态不抢先跳变），推荐指数百分比为真实分值（非 0%）。
- 主题跟随全局 mode（对齐原型 device 主题）。

## 6. Mock / API 切换控制台

**操作路径**：任意页 BrandHeader「更多」按钮 → 弹层。

**预期表现**：
- 弹层含：数据源切换（Mock/API，选中态明确）、清除本地状态、OpenAPI 说明。
- 切到 API 后 storage 持久化 + reLaunch；重启小程序仍为 API 模式（指向 `http://localhost:8020/api/v1`）。
- API 模式下首页推荐、菜单列表、详情、相似、对比均正常出数据：标签显示**中文 name_zh**（非英文 code）；推荐分非 0；雷达 0–10；无「字段恒空」回归。
- 「清除本地状态」后收藏/偏好清空并回初始态。

## 7. 收藏页文案与布局

**操作路径**：先收藏 2–3 款 → 底部 tabBar「收藏」。

**预期表现**：
- 头部文案为「**{n} 款已保存**」（fav-header 旧样式已移除）；卡片不显示 tags。
- 顶部有 mode-switch 入口（对齐原型 templates.js:122），切换只列当前域收藏。
- 「猜你喜欢」固定 **3 款**（slice(0,3)）。
- 宫格 3 列（窄屏 ≤370px 降级 2 列），宽屏不拉伸变形。
- 空态：无图标（对齐原型 empty-state），文案与原型一致。

## 8. 我的页统计卡与推荐弹层

**操作路径**：底部 tabBar「我的」→ 查看统计卡 → 点推荐入口。

**预期表现**：
- 统计卡数值（浏览历史/收藏/偏好计数）与实际行为一致；默认昵称 **Awakener**、头像字母 A（real 与 mock 一致）。
- 推荐以**弹层**形式呈现（非内联替换卡），弹层四要素齐备：推荐卡片 + 理由（buildReasons 保证非空，不得只剩「领域：咖啡」占位）+ 「换一批 / 换一杯 / 查看详情」按钮。
- 「换一杯」每次确实换不同产品（excludedDrinkIds 生效，不重复同款）。
- 底部 safe-area 生效，弹层遮罩与主题色一致。
