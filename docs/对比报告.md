# 原型严格对比报告 — xingxun-responsive-prototype vs miniprogram-v2

> 生成日期：2026-08-05
> 对比基准：`xingxun-responsive-prototype/`（可运行高保真原型，唯一事实来源 per AGENT-HANDOFF §1）
> 对比对象：miniprogram-v2/（重写实现）
> 方法：6 个独立方向 agent 深度对比（信息架构/数据契约/交互行为/视觉Token/文案枚举/响应式适配）
> 两条线：①原型内部一致性（docs vs js/styles vs 参考图）；②原型 vs miniprogram-v2
> 优先级：P0=功能缺失/契约错误，P1=体验偏离，P2=细节不一致
> 结论：**原型内部高度自洽**（仅 3 处 P1/P2 小瑕疵）；**原型 vs miniprogram-v2 共 P0×4、P1×27、P2×约35**，差异集中在真实后端契约层 + 双主题切换机制 + 底部导航缺失。

## 方向一：信息架构

### 原型内部一致性

- [P1] 对比页在移动端无导航入口 | 证据: templates.js:26-29（底部 tab 仅 4 项）vs templates.js:31-34（compare 仅桌面 railNav）；responsive.css:8-20 移动端隐藏 .design-rail | 影响: compare 在移动端只能 URL 直达
- [P2] 详情页模块顺序与规格不符 | 证据: templates.js:98-100 渲染 `detail-tabs → detail-hero`，PAGE-SPEC §3 内容顺序为「名称→海报→…」 | 影响: 首屏先见 Tab 栏而非海报
- [P2] 详情概览 tab 内容过载 | 证据: templates.js:108 overview 内联配方+雷达+步骤+相似 | 影响: 与 recipe/similar 重复

### 原型 vs miniprogram-v2

- [P0] **底部导航整体缺失** | 证据: 原型 index.html:46 #tabBar + templates.js:26-29（4 tab 全路由含 detail/compare 高亮菜单）；v2 app.json 无 tabBar 键、无 custom-tab-bar、全 navigateTo 栈式 | 影响: 4 个一级页面无平级切换，PAGE-SPEC 首页模块 8 未落地
- [P1] 对比页完全不可达 | 证据: v2 全工程无任何 navigateTo('pages/compare') | 影响: 对比功能成孤儿页
- [P1] 收藏页缺双模式切换入口 | 证据: 原型 templates.js:122 renderFavorites 顶部 modeSwitch；v2 favorites/index.wxml 仅静态 fav-mode-tag | 影响: 收藏页无法切换模式
- [P1] 详情页模块顺序与原型相反（Hero/Tab 互换）| 证据: 原型 detail-tabs→hero；v2 detail-hero→tabs | 影响: 首屏从海报变 Tab 栏
- [P1] 详情页导航栏双轨 | 证据: v2 app.json 未设 navigationStyle:custom + detail/index.wxml:8-14 自定义 topbar | 影响: 双返回按钮/双标题条
- [P2] 详情无 id 兜底不同 | 原型回退默认产品；v2 toast「缺少饮品 ID」| 影响: 边缘体验偏离
- [P2] 详情页主题绑定源不同 | 原型跟全局 mode；v2 跟饮品 domain | 影响: 跨模式浏览主题不一致
- [P2] 收藏页猜你喜欢 3 vs 4 个 | 影响: 细节差异
- [P2] 全局控制台在 v2 无运行时对应 | v2 数据源静态配置 | 影响: 开发态功能降级
- 无差异：6 页清单、对比模块顺序、对比维度行、详情 4 Tab、菜单筛选分组、我的页模块顺序、模式切换加载默认对比组

## 方向二：数据契约

### 原型内部一致性

- [P2] contracts.js DrinkSummary 缺 scene 字段 | contracts.js:21-31 vs openapi.yaml:325-327 | 纯 JSDoc 不一致
- [P2] contracts.js 缺 Profile/RecommendationResult/CompareResult 类型 | 仅 api.d.ts 定义
- [P2] openapi operationId `recommendDrink/compareDrinks` vs 方法名 `recommend/compare`
- [P2] mock compare 结论文案「清爽提神」vs templates 硬编码「夏日清爽」
- [P2] 雷达形态 [label,score] vs {key,label,score}（DATA-MAPPING 已记录）

### 原型 vs miniprogram-v2

- [P0] **`attributes` 真实路径恒空** | 证据: api-service.ts normalizeCard:241/normalizeDetail:269/normalizeCompare:303 恒 `attributes:{}`；server get_card 无该字段 | 影响: API 模式对比维度表全「—」
- [P0] **`recommendationScore` API 模式恒 0** | 证据: server projection 无该列，normalizeCard:240 `||0` | 影响: 推荐指数全显示 0%
- [P0] **雷达 0-5 vs 0-10 尺度未归一** | 证据: server 雷达 0.0-5.0（文档 02 §8:96），lib/radar.ts 按 max=10 归一化 | 影响: 雷达图缩小一半
- [P1] compare 参数契约偏差 | 原型 {drinkIds}；v2 只读 {leftId,rightId}，drinkIds 被忽略 | 影响: 单独传 drinkIds 会失败
- [P1] scene 丢失 | normalizeDetail:267 `scene:[]` | 影响: 适合场景维度显示「—」
- [P1] 相似项丢图丢简介 | server 相似项无 image/summary | 影响: 详情相似卡空图
- [P1] 分页字段伪造 | normalizePage 硬编码 page/pageSize/hasMore | 影响: 翻页判断失真
- [P1] EXCLUDE 筛选 API 模式被丢弃 | menu 只聚 WANT 进 menu；listDrinks 无 filters | 影响: 排除条件无效
- [P1] 筛选字典 key 不一致 | server menus key `sweet_bitter/base` 等 vs 对比页 `sweetBitter/baseSpirit` | 影响: 对比页 key 命不中
- [P1] preferences/updatePreferences 空操作 | API 模式偏好恒空、编辑空 | 影响: 偏好持久化不可用
- [P1] recommend 理由降级 | 无 query 时只剩「领域：咖啡」占位 | 影响: 推荐理由退化
- [P2] 信封形态 {data,meta} vs {code,message,data} | 影响: 若后端符合原型信封，code!='0' 被当成功
- [P2] 错误码集合不同 | PRODUCT_NOT_FOUND vs DRINK_NOT_FOUND | 语义等价
- [P2] 数据源切换简化 | 原型 URL/localStorage；v2 仅配置 | 小程序合理裁剪
- [P2] app-config 注释「'api'默认」与默认值 'mock' 矛盾 | 注释-实现不一致
- [P2] apiBaseUrl /api/v1 vs /api/v6 | 符合演进
- [P2] 图片双图 vs 单图 | normalizeDetail 把 posterUrl 指向 imageUrl | 影响: API 模式海报=列表图
- [P2] toggleFavorite 3-4 次请求 | GET+PUT/DELETE+GET | 效率低
- [P2] 原料 nameEn 恒空 | api-service.ts:221 | 详情配方英文名丢失
- [P2] 单位枚举 LEAF 未映射 | toIngredient 透传小写 leaf | 影响: 配方单位显示 leaf
- [P2] RadarMetric.label 变可选 | API 模式对比雷达维度名缺失

## 修复优先级建议

### P0（先修）
1. **双主题切换机制**（方向四）：把 `page[data-mode]` 选择器改为能命中根 `<view>`（如 `view[data-mode]` 或给 page 挂 class + 用 `.page[data-mode]`），并补导航栏变色（page-meta 或 wx.setNavigationBarColor）。这是当前 mock 模式也可见的最严重问题。
2. **底部导航**（方向一）：补 `tabBar`（首页/菜单/收藏/我的）或 `custom-tab-bar`，并给 compare 页加入口（可从菜单结果「对比」入口进）。
3. **真实后端契约**（方向二，API 模式）：attributes/recommendationScore/雷达尺度在 `normalizeCard/normalizeDetail/normalizeCompare` 补齐（或与 server 对齐字段）。
4. **标签渲染中文**（方向五）：`toTagCodes` 改为取 `name_zh`，real 数据源标签显示中文。

### P1（次修）
- EXCLUDE 筛选 API 模式接通（menu 传 exclude_codes 或 server 支持）
- 收藏乐观更新改为「成功再更新」
- 「换一杯」接入 excludedDrinkIds 排除当前品
- 收藏/我的页加 mode-switch 入口
- 详情页导航栏去重（设 navigationStyle:custom 或删自定义 topbar）
- 详情页 Hero/Tab 顺序对齐原型（或确认按 PAGE-SPEC）
- 鸡尾酒副标题文案改回原型
- 响应式：补窄屏/宽屏 @media 或确认 rpx 等比可接受

### P2（可选）
- 圆角/卡片/Toast/tag 视觉细节对齐
- scene/preferences/updatePreferences 对齐
- mode-switch 抽组件、keyword/detailTab 随模式清空
- 其余细节见各方向
