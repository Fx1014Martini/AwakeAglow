# 验收报告：miniprogram-v2 vs xingxun-responsive-prototype（1:1 还原度）

> 验收基准：`/v6/xingxun-responsive-prototype/`（Web 高保真原型，视觉与交互的**唯一事实来源** per AGENT-HANDOFF §1）
> 验收对象：`/v6/miniprogram-v2/`（TS + UnoCSS 重写版，默认 mock 数据源）
> 验收日期：2026-08-06
> 方法：11 个维度并行对比（6 页面 + 设计令牌/主题 + 导航框架 + 交互 + 数据契约 + 组件库）+ 逐条对抗性核实；并复核 2026-08-05 既有 `docs/对比报告.md` 与当前代码实况
> 换算规则：1 CSS px ≈ 1.923 rpx（AGENT-HANDOFF）；偏差 >2rpx 才算差异，颜色/文案/结构零容差

## 验收判定：**❌ 未通过（非 100% 1:1）**

当前 miniprogram-v2 **仍不满足**「100% 1:1 复制原型」要求。相对 2026-08-05 的对比报告，已有 1 项 P0 修复（底部导航已补），但仍有 **4 项 P0 + 约 27 项 P1 + 约 35 项 P2** 差异未闭环。其中多项 P0 在默认 mock 模式下即暴露，与是否接真实后端无关，属必须修复的可见缺陷。

### 差异计数总览

| 维度 | 原型内部 | 原型 vs v2（修复后实况） | 最严重项 |
|---|---|---|---|
| 一、信息架构 | 2 处 P1/P2 | 4 P0→**0 已修** + 8 P1/P2 | 底部导航已补；对比页入口仍缺失 |
| 二、数据契约 | 5 处 P2 | 4 P0（仍 3 未修）+ 8 P1 + 11 P2 | attributes / recommendationScore / 雷达尺度 |

| 四、视觉与 Token | 3 处 P1/P2 | 3 P0（仍 2 未修）+ 8 P1 + 若干 P2 | 双主题挂点错位 / 导航栏不变色 |

## P1 清单（次修，明显偏离体验）

### 方向一·信息架构
- [P1] 对比页不可达：全工程无 `navigateTo('pages/compare')` 入口（tabBar 4 项无 compare；菜单结果对比按钮需确认）。影响：对比功能成孤儿页。
- [P1] 收藏页缺模式切换入口：原型 templates.js:122 顶部 modeSwitch；v2 favorites/index.wxml 仅静态 `fav-mode-tag`。
- [P1] 详情页模块顺序相反（Hero/Tab 互换）：原型 detail-tabs→hero；v2 detail-hero→tabs。
- [P1] 详情页导航栏双轨：app.json 未设 `navigationStyle:custom` 而 detail/index.wxml:8-14 自绘 topbar → 双返回/双标题。
- [P2] 详情无 id 兜底：原型回退默认产品，v2 toast「缺少饮品 ID」。
- [P2] 详情主题绑定源不同：原型跟全局 mode，v2 跟饮品 domain。
- [P2] 收藏页猜你喜欢 3 vs 4 个。

### 方向二·数据契约
- [P1] compare 参数契约偏差：原型 `{drinkIds}`；v2 只读 `{leftId,rightId}`，`drinkIds` 被忽略。
- [P1] scene 丢失：normalizeDetail:267 `scene:[]` → 适合场景维度「—」。
- [P1] 相似项丢图丢简介：server 相似项无 image/summary → 详情相似卡空图。
- [P1] 分页字段伪造：normalizePage 硬编码 page/pageSize/hasMore → 翻页判断失真。
- [P1] EXCLUDE 筛选 API 模式被丢弃：menu 只聚 WANT，listDrinks 无 filters → 排除条件无效。
- [P1] 筛选字典 key 不一致：server menus key `sweet_bitter/base` vs 对比页 `sweetBitter/baseSpirit` → key 命不中。
- [P1] preferences/updatePreferences 空操作：API 模式偏好恒空。
- [P1] recommend 理由降级：无 query 时只剩「领域：咖啡」占位。

### 方向三·交互行为
- [P1] 收藏乐观更新违背「失败不残留」：stores/index.ts:251-264 先乐观后回滚；原型 app.js:181-189 先 Service 成功再更新。
- [P1] 「换一杯」不真正换一杯：home/index.ts:251-253 传 activeScene；mock 不排除当前品 → 反复点显示同款。
- [P1] 详情页无模式切换触发点（原型 app.js:163 规则不可达）。
- [P2] switchMode 未清 keyword/detailTab 残留搜索词。
- [P2] profile 推荐无弹层（v2 内联替换卡）。
- [P2] detailTab 不持久化（persist:false）。
- [P2] 概览 Tab 缺相似入口。

### 方向四·视觉与 Token
- [P1] detail-tabs 选中态：原型浅底+下边框 → v2 仅下划线（tabs/index.wxss vs app.css:146-148）。
- [P1] result-card 圆角 22px → 16px（menu/index.wxss vs app.css:130）。
- [P1] 对比页第二雷达暖棕 → 金色（radar-chart wxss vs templates.js:92）。
- [P1] toast 咖啡主题反色（toast/index.wxss vs app.css:259）可读性下降。

### 方向五·文案与枚举
- [P1] 鸡尾酒首页副标题措辞改变：原型「根据时间、心情与场景，为你推荐最合适的一杯」；v2 home/index.ts:40 改为「根据此刻的心情与场景，挑选属于你的那一杯」（违反 AGENT-HANDOFF「禁止改变文案」）。
- [P1] real 数据源标签渲染英文 code：api-service.ts:205-207 toTagCodes 只取 `t.code` → 显示「MILK_COFFEE」而非「奶咖」；server 带 name_zh 被丢弃。

### 方向六·响应式适配
- [P1] 全局零 @media：原型 3 档手机断点未复现。
- [P1] 无分机型策略（SE/15/Android Compact/Large）。
- [P1] 窄屏降级锁死 / 宽屏放大缺失：收藏恒 2 列（原型宽 3 列）、详情恒单列、结果图恒 192rpx。
- [P1] 页面 padding 用物理 px 未按 1.923 换算：`0 16px 32px` 应约 `0 30.8rpx 61.5rpx`。

## P2 清单（细节打磨，归类）

- **视觉**：tag 圆角矩形→胶囊（--td-radius-round）；无 reduced-motion / --ease-spring（可访问性退化）；组件尺寸普遍偏小 4-10%；主按钮/爱心按钮触控略低于规范；detail-hero 480rpx≈250px 仅原型 345px 的 72%。
- **交互**：mode-switch 未抽共享组件（home/menu 内联重复）；Cmd/Ctrl+K 未迁移（移动端无影响）；事件委托→bindtap（预期内）。
- **数据**：信封形态 `{data,meta}` vs `{code,message,data}`；错误码 `PRODUCT_NOT_FOUND` vs `DRINK_NOT_FOUND`（语义等价）；apiBaseUrl `/api/v1` vs `/api/v6`（符合演进）；图片双图 vs 单图；toggleFavorite 3-4 次请求；原料 nameEn 恒空；单位枚举 LEAF 未映射（透传小写 leaf）；RadarMetric.label 变可选。
- **文案**：服务端风味倾向多 1 项「清淡均衡」（8 vs 7）；enums.json「COLD=冷饮」vs 筛选词「冰饮」；mock 对比结论「轻松放松」→「清爽提神」；real 默认昵称「醒醺用户」vs mock「Awakener」；enumCn 字典未注册（setEnumsDict 仅 core.ts:90 定义无调用）。
- **适配**：.safe-top/.safe-bottom 死代码；favorites/profile 底无 safe-area-inset-bottom；顶部 icon-button 触控 38px < 规范 44px。

## 修复优先级（达成 1:1 的必经路径）

### 第一优先（P0，阻断验收）
1. **双主题切换机制（P0-2/P0-3）**：把 `page[data-mode]` 改为命中根 `<view data-mode>`（如 `view[data-mode]` 或给 page 挂 class + `.page[data-mode]`），并用 `wx.setNavigationBarColor` / `page-meta` 补导航栏变色。当前 mock 模式也可见的最严重问题。
2. **真实后端契约补齐（P0-4/5/6）**：`normalizeCard/normalizeDetail/normalizeCompare` 补齐 `attributes` / `recommendationScore`，并与 server 对齐雷达尺度（0-5 → 对外 ×2 归一 0-10，或后端直接给 0-10）。

### 第二优先（P1）
- 对比页加可达入口（菜单结果「对比」按钮 / 详情相似卡跳转）。
- EXCLUDE 筛选 API 模式接通；收藏乐观更新改为「成功再更新」；「换一杯」接入 `excludedDrinkIds`。
- 收藏/我的页加 mode-switch 入口；详情页导航栏去重（设 `navigationStyle:custom` 或删自绘 topbar）。
- 详情页 Hero/Tab 顺序对齐原型；鸡尾酒副标题文案改回原型。
- 标签渲染中文（`toTagCodes` 取 `name_zh`）。
- 响应式：补窄屏/宽屏 @media 或将 padding 改用 rpx 等比。

### 第三优先（P2）
- 圆角/卡片/Toast/tag 视觉细节对齐；scene / preferences / updatePreferences 对齐；mode-switch 抽组件、keyword/detailTab 随模式清空；其余见各维度。
